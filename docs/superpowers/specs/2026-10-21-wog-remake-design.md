# WOG 翻新版設計文件（v2，取代 2026-10-21-inkbound-design.md 的遊戲系統部分）

- 日期：2026-10-21
- 狀態：accepted（使用者於 2026-10-21 決定：照搬 WOG 單人系統、畫面改成現代奇幻風）
- 依據：`docs/research/wog-research-{stats-jobs,battle,items,world}.md`（從 WOG 4.5 原始碼推出的規則；SQL 資料遺失，所有「數值表」都要自行設計）
- 標記：**〔使用者決定〕**／**〔Claude 的判斷〕**（可推翻）／**〔WOG 原規則〕**（照搬，附研究報告出處）

## 0. 這份文件取代什麼

v1 設計文件（`2026-10-21-inkbound-design.md`）中的**遊戲系統**（境界、經脈、銘文、功法、渡劫、水墨風格）全部作廢。v1 的**技術架構**（§6：.NET 10 後端、規則只在 Domain、MySQL＋Flyway＋Database-First、React＋Pixi 前端、播放模型、推進 API、離線結算方向）與**開發方式**（§7）繼續有效。已完成的計畫 1、2 全部沿用，只換內容與外觀。

專案代號維持 `Inkbound`，遊戲顯示名稱暫時沿用「墨渡」，之後由使用者決定是否更名。〔Claude 的判斷〕

## 1. 意圖

**翻新 WOG**：把 WOG 4.5 的單人遊戲系統原汁原味搬過來（能力值、職業樹與轉職、6 格裝備、技能熟練度、21 個地區、商店、旅館、寵物、傭兵、任務），去掉多人部分（公會、拍賣、PK、組隊、聊天、交易所、論壇整合），把當年要靠外掛的掛機做成正式的放置玩法，畫面換成現代奇幻風格、手機優先。〔使用者決定〕

成功的樣子：老玩家一眼認得出「這是 WOG」，數字長法、職業名、地名都熟悉；但不用再開外掛，手機也能玩。

### 非目標
- 多人內容（上列）。
- 原創的修仙／經脈／銘文系統。
- 商城（釋出版本身就是空殼）、驗證碼、防外掛問答、推薦人、SNS、好友、玩家互寄信。

### 反目標
- 數值體系和 WOG 對不上（例如改成百分比成長），老玩家會覺得不是 WOG。
- 為了「現代化」把系統砍到只剩打怪升級。

## 2. 核心循環

1. 角色在選定的**地區／子地區**自動戰鬥（一場 = 最多 40 回合，一次算完），消耗 1 點**行動力**。
2. 勝利得經驗、金錢、職業熟練度、掉落物；升級時能力值依**職業成長範圍**隨機增加。
3. 玩家花熟練度學技能、裝備欄位、買賣裝備、精鍊鑲嵌，達標後**轉職**到上級職業。
4. 死亡（HP 0）必須**住宿**才能再戰；行動力耗盡則收益減半、戰鬥變慢。
5. 離線期間照樣結算（伺服器端），上線時顯示摘要。

## 3. 角色與能力值〔WOG 原規則，出處 stats-jobs §1–3〕

### 3.1 七項基礎能力與衍生值

| 能力 | 欄位 | 影響 |
|---|---|---|
| 力量 | str | 物攻 at |
| 智力 | smart | 魔攻 mat、SP 上限 |
| 生命 | life | HP 上限 |
| 體質 | vit | 物防 df |
| 敏捷 | agi | 先攻、物理命中與閃避、物理暴擊 |
| 魅力 | au | 魔法暴擊、寵物代擋率 |
| 信仰 | be | 魔防 mdf、SP 上限 |

每項都有 `base_*`（裸點）與總值（裸點＋裝備＋鑲嵌＋精鍊）。面板顯示裸點，括號內顯示加成。

```
at    = Σ裝備 d_at  + 鑲嵌 + 精鍊 + str(總)
mat   = Σ裝備 d_mat + … + smart(總)
df    = Σ裝備 d_df  + … + vit(總)
mdf   = Σ裝備 d_mdf + … + be(總)
hpmax = round(life(總) × 25) + 50 + 鑲嵌 s_hpmax
spmax = round((smart(總) + be(總)) × 3) + 25
```
升級、換裝、轉職後重算；hp／sp 不自動補滿。

### 3.2 創角
- 可分配 **10 點** 到 力量／智力／生命／敏捷，每項至少 1；底值每項 +10；體質／魅力／信仰固定 10。
- 初始 HP 50／SP 25／金錢 2000／Lv 1／下一級經驗 1000。
- 選擇：性別（1 男 2 女）、屬性（1 地 2 水 3 火 4 木 5 風 6 毒）、出生地（1 中央大陸 2 魔法王國 3 熱帶雨林 4 末日王城）、起始職業（四個基礎職業之一）、必殺技名稱（暴擊時顯示）。
- 計畫 1 的帳號／角色表要擴充，既有的 `experience`／`spiritStones` 改為 `p_exp`／`p_money` 語意。〔Claude 的判斷〕

### 3.3 升級
```
while exp > nextexp:
    lv += 1; exp -= nextexp
    nextexp = 6·lv² + 1080·lv
    七項能力各 += rand(min, max)   // 範圍取自「當時職業」的成長表
```
沒有等級上限、沒有升級配點。升級不回血。

### 3.4 行動力〔WOG 原規則，battle §1.8〕
- 每場戰鬥消耗 1；每 180 秒回 6，上限 50。
- 行動力 ≤ 0：戰鬥間隔由 2 秒變 12 秒，經驗／金錢／職業熟練度 ×0.5，掉率分母 ×1.5。
- 放置版本：伺服器結算時依時間軸模擬回復與消耗，所以長時間掛機自然會進入「減半」狀態，這正是 WOG 掛機的節奏。〔Claude 的判斷〕

## 4. 戰鬥〔WOG 原規則，battle §1〕

一場戰鬥在伺服器一次算完，輸出逐回合事件給前端播放（沿用播放模型）。

- **先攻**：玩家 agi 較高 70% 先攻，否則 30%。
- **攻擊方式**：玩家可指定物理／魔法；未指定時 at ≥ mat 走物理，否則 80% 魔法 20% 物理。（WOG 的 else 分支恆為物理是 bug，這裡用意圖中的 80/20。〔Claude 的判斷〕）
- **物理命中**：`agi/(agi+敵agi)×100 + rag + 20 > rand(1,100)`；魔法必中。
- **暴擊**：基礎 10%、×1.2；攻方 agi（魔法用 au）高於守方時，機率 `min(20, 比值×10)`，倍率 `min(比值×1.2, 2)`；技能可加 `act/mct`。怪物側沿用與玩家相同的正確公式（原程式的反向比值是 bug）。〔Claude 的判斷〕
- **傷害**：
  ```
  fight(A, D, s, def_dmg=1, get_dmg=0):
      D = max(D,1); A = max(A,1)
      d = (A·(A/D) − D) × s ; if d ≤ 0: d = 1
      d += rand(⌊d/A/3⌋, ⌊d/A/2⌋)
      return round(d × def_dmg + get_dmg)
  ```
  物理用 (at×暴擊倍率, 敵 df)，魔法用 (mat×暴擊倍率, 敵 mdf)。
- **屬性**：地→水→火→木→風→毒→地 循環，剋制 ×1.2、被剋 ×0.8，其餘 ×1。武器屬性覆蓋角色屬性。怪物屬性 0 視為無屬性（一律 ×1）。〔0 的處理是 Claude 的判斷〕
- **回合上限 40**：超限時依累計傷害比例給部分經驗（`m_lv×0.6`、傷害／1.5），沒有金錢，算失敗但不計敗場。
- **自動補給**：第二道具欄的補給品，當 `HP < hpmax×15%` 且 `SP < spmax×100%` 時使用，每場最多 9 次；門檻玩家可調。
- **死亡**：HP 0，無經驗／金錢懲罰，但必須住宿（§7.4）。
- **逃跑**：預設關閉（HP 門檻 0%）；開啟時成功率 10%。
- **經驗**：
  ```
  base = (m_at + m_mat)/2 ; e = rand(base, base + m_lv)
  if p_lv ≤ 100: e ×= 1.3 ; if m_lv ≥ 450: e ×= 0.6
  e = m_lv × e × (m_lv / p_lv) × (m_hp/m_hpmax) × 0.18
  if 未擊殺: e ×= (m_hp/m_hpmax)
  if p_lv ≤ 15: e ×= 2.5
  exp = round(e × 2 × f_down)
  ```
- **金錢**：`rand(m_lv/2.5, m_lv) × rand((m_at+m_mat)/m_lv, m_hp/(m_at+m_mat)×0.4) × 0.4 × f_down`（rand 參數顛倒時自動對調）。
- **掉落**：每個 (item, topr) 配對獨立 `rand(1, topr×0.9) ≤ 1`；行動力不足時 topr ×1.5；背包滿則丟棄並提示。
- **職業熟練度**：擊殺時 `ch_<job> += m_job_exp×f_down`、`sk_<job> += 同值`。

## 5. 職業〔WOG 原規則＋使用者要求，stats-jobs §4〕

| 階 | 職業 | 前置 | 解鎖等級 | 定位 |

| 基礎 | 戰士 | — | 1 | 力量／體質 |
| 基礎 | 術士 | — | 1 | 智力／信仰 |
| 基礎 | 盜賊 | — | 1 | 敏捷 |
| 基礎 | 樂手 | — | 1 | 魅力 |
| 進階 | 狂戰士 | 戰士 | 30 | 高攻低防 |
| 進階 | 騎士 | 戰士 | 30 | 高防 |
| 進階 | 魔導師 | 術士 | 30 | 高魔攻 |

### 5.2 轉職條件
- 等級 ≥ 解鎖等級。〔WOG〕
- 前置職業熟練度 `ch_<前置>` ≥ 門檻（顯示為 `floor(x/3500×100)%`，3500 = 100%）。〔WOG〕
- **能力值門檻**：每個進階職業要求 1～2 項裸點達標（例如狂戰士 力量 ≥ 60、騎士 體質 ≥ 60）。〔使用者要求〕
- 無金錢或道具成本；可隨時換回基礎職業（也可在同階之間轉換，只要各自條件達標）。〔WOG＋Claude 的判斷〕
- 轉職後：等級、經驗、裸點不變；**裝備全部卸下**回背包；被動技能欄清空；之後每級的成長範圍改用新職業。〔WOG〕

### 5.3 成長表
每職業七項能力各有 `"min,max"`。設計原則：基礎職業每級總成長約 7～9 點，進階約 9～12 點，定位能力的範圍明顯較高。具體數值在內容 JSON 由實作者設計，須附一份 Lv1→Lv100 的期望值試算。

### 5.4 熟練度
- `ch_<job>`：累積，只增不減，用於轉職。
- `sk_<job>`：可花用，學技能時扣除。
- 兩者在擊殺時同時增加 `m_job_exp`。

## 6. 技能〔WOG 原規則，battle §3〕

- 技能屬於職業，有等級（每級一筆：SP 消耗、持續回合、發動時機、發動率、前置技能、學習費、所需熟練度）。
- 學習：未擁有或可升級、前置達標、`sk_<job> ≥ ch_exp`、金錢 ≥ 費用；成功扣兩者。
- 裝備：3 個主動欄（玩家自訂發動率）、2 個被動欄（只能放當前職業技能、用技能自己的發動率）、武器附帶技能第 6 欄。
- 戰鬥中每次攻擊前依序擲骰施放；持續技能以「回合開頭快照＋重套」實現。
- 目錄：第一版實作 WOG 的 0～30 號中約 **16 個**核心技能（爆氣、魔力增幅、連擊、急影、硬甲、魔甲、物減傷、魔減傷、嗜血、治癒、物暴擊率、靡靡之音、附加傷、戰神之怒、暈眩、反擊、仁義、魔連擊、冥想、減益、魔劍、魔盾），分配到 12 個職業。〔Claude 的判斷〕其餘後續補。

## 7. 世界、地區、旅館〔WOG 原規則，world §1〕

- 4 大區 21 地區，每地區 4 個子地區（禁區 17～20 需鑰匙，黑曜神廟無子地區）：
  - 中央大陸：1 中央平原、3 黑暗沼澤、7 王者之路、13 水晶之間
  - 魔法王國：2 試鍊洞窟、8 幻獸森林、12 天空之城、15 最果之島
  - 熱帶雨林：4 迷霧森林、11 無淵洞窟、16 冷峰寒地、9 星河異界
  - 末日王城：10 灼熱荒漠、5 古代遺跡、6 久遠戰場、14 失落古船、21 血之魔域
  - 禁區：17 廢棄洞窟、18 日沒碉堡、19 靜止之城、20 黑曜神廟
- 子地區名稱沿用 `js/wog_data.js` 的 `sec[]`。
- 移動免費、無等級限制；`wog_area_lv` 只用於「推薦地區」提示。
- 怪物選取：`m_place in (地區, 0)`、`m_meet ≤ rand(0,100)`、子地區位元遮罩，候選中均勻隨機。
- **旅館**：Lv ≤ 100 免費回滿；Lv > 100 收 `round(10 × lv × 係數)`（死亡 2.1、HP<10% 1.8、否則 1.4×缺血比例，下限 10×lv），付不起則免費但經驗 ×0.8；等待 5 秒，死亡 15 秒。
- **銀行**：Lv ≥ 15 可存，隨時可領。

### 7.1 放置化〔Claude 的判斷〕
- 玩家選定地區／子地區後自動連戰；每場之間 2 秒（行動力耗盡 12 秒）。
- 死亡時自動住宿（可設 HP／SP 門檻），住宿等待時間計入時間軸。
- 離線結算：超過 5 分鐘的部分用統計方式估算（平均每場收益 × 場數，掉落依機率抽），含行動力與住宿的節奏。

## 8. 道具、裝備、經濟〔WOG 原規則，items〕

- 道具分類：武器、頭、身、手、腳、道具（消耗／材料／補給）、魔石、勳章、鑰匙、精鍊石；屬性欄位 at/mat/df/mdf、七項能力加成、補給量 hp/sp、需求（力／智／敏／魅 裸點、職業）、屬性、孔數、精鍊上限、售價、商店等級 1～7、綁定。
- **沒有等級需求、沒有耐久**。
- 裝備 6 格：武器、頭、身、手、腳、道具欄 1；另有道具欄 2 放補給品（自動使用）。
- 背包：每分類 15 格（道具與魔石可擴充），堆疊上限 99；倉庫 20 格；賣給商店 50%。
- 商店：依分類與等級分頁，只賣 `d_dbst = 0` 的品項。
- **精鍊**：第 n 級成功率 `101 − 10n %`，失敗只損石頭（或安全石），裝備不壞，無金錢成本；上限 `d_plus`。
- **鑲嵌**：孔位 ≤ 孔數、同裝備不可重複同種魔石；隨機魔石鑲嵌當下擲骰；拆除需道具、24% 回收；打洞需道具、8% 成功。
- **合成**：配方制，1000／次（成功才扣），材料不論成敗都消耗。
- 消耗品：能力藥水（永久加裸點）、行動力藥水、背包／倉庫擴充、密藥（限時倍率）、寶箱、技能書、心得書。

## 9. 任務、寵物、傭兵、榮譽、冠軍〔WOG 原規則，world §2–5；後期〕

- **任務**：接取條件（職業／等級／性別／出生地／前置）、殺怪計數、交付需求物、獎勵（物品／金錢／技能／寵物）、經驗 `m_lv×190`、同時 3 個、每日隨機任務 09:00 重置。
- **寵物**：最多 3 隻；捕捉（副手捕捉道具，12%）、餵食（能力不可超過主人）、飢餓、老化；戰鬥只代擋（WOG 寵物傷害被歸零——重製時**恢復傷害**〔Claude 的判斷〕）。
- **傭兵**：購買後指定地區自動戰鬥，收益打折、次數制——放置版改為「第二條離線時間軸」。
- **榮譽商店**：勳章換物品。
- **冠軍**：改為 NPC 冠軍快照，500 金挑戰，贏了以自己的快照取代。

## 10. 畫面：現代奇幻風〔使用者決定；具體方向是 Claude 的判斷〕

- **基調**：深色介面。背景 `#121826`（深藍黑）→ `#1b2232`；面板 `#222b3d`；文字 `#e8ecf4`；主強調 **琥珀金 `#e0a63a`**（經驗、金錢、重點按鈕）；次強調 **冷青 `#4cc3d9`**（魔法、SP）；危險 **緋紅 `#e2554f`**（HP、暴擊）；成功 **翠綠 `#4fc47a`**。
- **字型**：Noto Sans TC（介面）＋ 標題用 Cinzel（拉丁）／Noto Serif TC 700（中文），營造奇幻感。
- **元件**：卡片式面板、圓角 12px、細邊框 1px `#2e3950`、數值條（HP 紅、SP 青、EXP 金）帶微光；按鈕實心金或描邊。
- **舞台**：維持 Pixi 舞台與特效，但換成夜色遠景（山脊剪影改深藍紫、底部霧氣），劍氣改金白、暴擊改緋紅閃光、傷害數字用粗體無襯線；沒有圖時妖怪顯示**橫排**名稱牌（黑底金邊）。
- **資訊密度**：WOG 的角色面板是數字表，現代版要保留「看得到所有數字」，用兩欄表格＋進度條。
- 手機直式優先、電腦置中 480px 的規則不變。
- 所有顏色仍只在 `theme.css` 變數與 `palette.ts`。

## 11. 技術架構（沿用 v1 §6，補充）

- 內容資料（職業成長表、技能、怪物、道具、地區）放 `backend/content/*.json`；玩家狀態在 MySQL。
- 戰鬥事件型別擴充：`round`、`attack`（含 physical/magic、hit/miss、critical、element 倍率）、`skill`、`potion`、`defeat`、`reward`（exp/money/jobExp/drops）、`levelUp`（含成長）、`rest`（住宿）、`encounter`。
- 推進 API 維持「依經過時間模擬」，但單位從「秒數時間軸」改為「場次＋回合」，前端以固定節奏播放（1 回合約 0.8 秒）。〔Claude 的判斷〕

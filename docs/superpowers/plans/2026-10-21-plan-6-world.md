# 計畫 6：世界 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把單一測試關卡換成 WOG 的世界：4 大區 21 地區、每地區 4 個子地區（黑曜神廟除外）、推薦等級提示、依地區與子地區篩怪的怪物池（約 65 隻依等級公式生成並手調的怪物），玩家能在冒險畫面選擇地區與子地區後自動連戰。禁區（17～20）列出但鎖住，鑰匙留到計畫 10。

**Architecture:** 世界資料是內容（`backend/content/world.json`、`monsters.json` 加 `placeId`／`subPlaces`），啟動時載入驗證。Domain 新增 `World/`（區域、地區、子地區定義與 `MonsterPool` 選怪規則），`StageDefinition` 整個移除。角色改存 `current_place_id`／`current_sub_place`（V6），舊的 `current_stage_id` 改為可空且不再使用。API 新增 `/api/world`（列表與推薦）與移動端點；前端在冒險分頁加「地區選擇」面板，標題顯示「{地區}・{子地區}」。

**Tech Stack:** 沿用。

**Spec:** `docs/superpowers/specs/2026-10-21-wog-remake-design.md` §7、§7.1；研究依據 `docs/research/wog-research-world.md` §1、`wog-research-battle.md` §2。

## Review Focus

- **沒有候選怪**：選了子地區但該子地區沒有怪（或 meet 全部不通過）時，退回該地區全部怪，不會卡住或丟例外。→ Task 4 `Pool_FallsBackToPlace_WhenSubPlaceHasNoCandidates`。
- **黑曜神廟無子地區**：移動到 20 時 `subPlace` 必須為 null，傳子地區 → 400；列表不顯示子地區。→ Task 5 `Move_RejectsSubPlace_ForPlaceWithoutSubPlaces`。
- **禁區鎖住**：移動到 17～20 → 400 `restricted`，角色位置不變；列表標示鎖住。→ Task 5 `Move_RejectsRestrictedPlace`。
- **舊角色升級資料**：V6 之前建立的角色（只有 `current_stage_id`）在遷移後位於 中央平原・香茅綠地，推進不會失敗。→ Task 3 `Migration_BackfillsPlaceForExistingCharacters`。
- **推薦提示**：等級落在推薦範圍內的地區標示「推薦」，低於下限的地區標示「偏難」，高於上限標示「偏易」；禁區不標。→ Task 5 `World_MarksRecommendation`。

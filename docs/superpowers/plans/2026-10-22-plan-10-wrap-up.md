# 計畫 10：收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 EBO 收成「一個指令就能跑、玩起來不會被缺陷咬到」的完整版本：完整 docker compose（MySQL＋Flyway＋API＋前端）與執行手冊；WOG 戰鬥設定面板（攻擊方式、補給／住宿／逃跑門檻、必殺技名稱）；禁區鑰匙；遺漏的 WOG 消耗品（魔石寶箱、精鍊寶盒、寵物蛋、心得書、經驗膠囊、密藥）與異類精鍊石合成；新手區數值平衡；計畫 6～9 延後的缺陷、整理與測試；美術圖檔規格與生圖提示詞範本；最後的文件與裁定彙整。

**Architecture:** 沿用既有分層，不新增專案。玩家設定是 `characters` 的新欄位（`Character.Settings`）；禁區通行與密藥各一張玩家狀態表（`character_area_passes`、`character_buffs`），鑰匙、寶箱、密藥等都是 `items.json` 的新道具，效果規則在 Domain（`World/AreaKeys`、`Items/ConsumableUse`、`Items/Buffs`、`Forge/StoneMerge`）。內容檔移除的道具在 repository 讀取時略過。compose 以 profile `app` 加上 `api`（ASP.NET 執行映像）與 `web`（nginx 提供前端並反向代理 `/api`），不帶 profile 時行為與現在相同。

**Tech Stack:** 沿用（.NET 10、EF Core Database-First、Flyway 11、MySQL 8.4、xUnit v3＋Testcontainers、React 19、PixiJS 8、Vitest）；新增 nginx 1.27-alpine、node 24-alpine（建置用）、ImageMagick 7（只有匯入美術的腳本用）。

**Spec:** `docs/superpowers/specs/2026-10-21-wog-remake-design.md` §12 第 10 列（完整 docker compose、美術圖檔規格與生圖提示詞範本、禁區鑰匙、遺漏的 WOG 消耗品）、§4（攻擊方式、自動補給門檻、逃跑）、§7／§7.1（禁區、住宿門檻）、§8（消耗品）、§10（畫面）、§11（技術架構）、§1（目標／非目標）。延後項目來源：記憶檔 `ebo-plan-10-backlog.md`（計畫 6～9 的 SDD 帳本已刪，這是唯一清單；逐條分派見文末「延後項目分派」）。研究依據 `docs/research/wog-research-items.md` §3.4／§5.1、`wog-research-world.md` §1／§5／§6，並以 PHP 查證：`wog_fight.php:90-111, 238-282`（`f_hp`／`f_sp`／`escape_hp` 範圍、`key_check`／`key_use`）、`js/wog_fight.js:63-90, 196-201`（設定面板文案）、`class/wog_fight_m.php:726-760, 811-826, 921-935`（補給、逃跑、密藥經驗倍率）、`forum_support/function.php:398-416`（密藥能力倍率）、`class/wog_act_arm.php:826-921, 1014-1237`（寶箱、精鍊寶盒、物品使用 `d_type`）、`class/wog_act_plus.php:100-137`（異類合成）、`language/*.php`（UTF-8）。

- **冒險設定**（WOG 戰鬥設定面板，`js/wog_fight.js:196-201`；spec §4、§7.1）：`AdventureSettings(AttackKind? Attack, int PotionHpPercent, int PotionSpPercent, int RestHpPercent, int RestSpPercent, int EscapeHpPercent)`，預設 `(null, 15, 100, 15, 15, 0)`（= 計畫 9 的固定行為）。範圍：補給與住宿 **−1～100**（−1 = 略過該條件，WOG 住宿欄的寫法 `-1表示略過條件`，這裡也用在補給〔Claude 的判斷：WOG 補給 SP 預設 100% 時 SP 全滿永遠不喝，給玩家關掉 SP 條件的方法〕），逃跑 **0～100**（0 = 不逃）；超出範圍 400 `invalidPercent`（WOG 是靜默改回預設〔Claude 的判斷〕）。條件一律用整數比較：補給 `(HpPercent < 0 || hp×100 < HpPercent×hpMax) && (SpPercent < 0 || sp×100 < SpPercent×spMax)`；住宿 `hp == 0 || (RestHp ≥ 0 && hp×100 < RestHp×hpMax) || (有裝備技能 && RestSp ≥ 0 && sp×100 < RestSp×spMax)`。

- **新消耗品**（`wog_act_arm.php` 的 `d_type`；名稱與數值是 Claude 的設計，WOG `wog_df_used` 資料遺失）：`ConsumableKind` 依序追加 `StoneBox, RefineBox, PetEgg, ProficiencyBook, ExperienceCapsule, Elixir`。魔石寶箱：`r = rand(1,100)`，`r ≤ 60` 等級 1、`61～90` 等級 2、`91～100` 等級 3；候選 = `Stone.BoxClass` 在 1～等級內的魔石；抽 `Amount` 顆**不重複**（`random.NextInt(剩餘數)` 逐顆抽出移除；WOG `d_lv 4 → limit 2`）。精鍊寶盒：等級 = `Amount` 的精鍊石中 `random.NextInt(n)` 一顆。寵物蛋：寵物數 ≥ 3 → 400 `petsFull`、不消耗；否則從 `MissionId == null` 的全部怪物 `random.NextInt(n)` 抽物種，`PetCapture.NewPet(怪物, Amount, now, random)`（WOG `up=280`、放獸欄）。心得書：**目前職業**的技能點 `sk_ += Amount`，熟練度 `ch_` 不變〔Claude 的簡化：WOG 綁定 `ch_id`〕。經驗膠囊：`Exp += Amount` 後立刻 `LevelUp.Apply`〔Claude 的判斷：WOG 只加 `p_exp`，下一場勝利才升級〕。開箱結果放不進背包 → 400 `bagFull`，什麼都不寫（寶箱不消耗；WOG 同樣擲完才擋）。

## Review Focus

- **禁區通行證在離線期間到期**：只結算到到期時刻為止的戰鬥，之後不再打怪、不發獎勵、不偷扣鑰匙；回來時冒險頁顯示通行已結束，用鑰匙可以再次進入同一地區。→ Task 4 `Advance_StopsAtAreaPassExpiry`、`Advance_AfterExpiryFightsNothingAndMovesSettlementToNow`、`Move_ReentersSameRestrictedPlaceWithKeyAfterExpiry`。
- **調整補給／住宿門檻時，還沒結算的時間**：存設定前先以舊設定結算到現在，新設定不回溯；SP 填 −1 時 SP 全滿也會喝；HP 填 0 永遠不喝；101 或 −2 一律 400 `invalidPercent`、什麼都不寫。→ Task 3 `UpdateSettings_SettlesElapsedTimeWithOldSettings`、`ShouldUse_SkipsSpConditionWhenMinusOne`、`ShouldUse_ZeroHpPercentNeverDrinks`、`UpdateSettings_RejectsOutOfRangeAndWritesNothing`。
- **背包或牧場已滿時使用新消耗品**：魔石分類 15 格滿時開寶箱、已有 3 隻寵物時用寵物蛋 → 400（`bagFull`／`petsFull`），道具數量、背包、寵物、角色版本都不變。→ Task 5 `Use_StoneBoxRejectedWhenStoneBagFull`、`Use_PetEggRejectedWhenPetsFull`。
- **內容檔移除了玩家持有的道具 id**：背包、`/me`、推進、倉庫都照常 200，那一列在畫面上消失（資料庫保留，內容加回來就恢復），而不是整個帳號 500。→ Task 8 `List_SkipsRowsWhoseItemIsNotInContent`、`RemovedItem_DoesNotBreakInventoryMeOrAdvance`。
- **密藥在推進中途到期、或在尚未結算的時間之後才喝**：只有開打時刻落在 `[StartsAt, EndsAt)` 的場次有加成；喝下前那段尚未結算的戰鬥不吃加成。→ Task 6 `Adventure_ElixirAppliesOnlyWithinItsWindow`、`Use_ElixirDoesNotApplyToUnsettledFightsBeforeIt`。

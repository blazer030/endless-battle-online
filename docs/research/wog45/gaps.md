# WOG 4.5 匯入缺口

由 `scripts/import-wog45.py` 產生，不要手改。列出原版有、但現有規則還用不到的紀錄與欄位，以及匯入時的對照方式；後續補規則的變更以這份清單為範圍。

## 道具

### 對照方式

- 裝備：`at`、`mat`、`df`、`mdf` 與 `bonus` 合併成 `bonus`；屬性的地水火木風毒轉成 1～6。
- 原版「道具」欄（d_fie 5）有能力或需求的轉成飾品（Accessory），其餘轉成材料（Material）。
- 商店等級 0 或禁售的道具 `shopSellable` 為 false；不在商店的道具 `shopLevel` 寫 1（欄位必填，沒有作用）。
- 魔石的 class 1～3 是寶箱分級，轉成 `boxClass`；class 0、4 不從寶箱出（`boxClass` 0）；class 99 是隨機魔石。
- 背包、倉庫擴充：原版是「容量設為 d_g_bag」，本作是每張加 `amount` 格，`amount` 取 d_g_bag。
- 心得書：原版綁定職業（ch_id），本作只加目前職業（裁定彙整第 98 行），`amount` 取 d_g_exp。
- 鑰匙在任務 4.1 與榮譽商店一起切換：現有規則每個禁區只能有一把鑰匙，擴充期間先不匯入原版鑰匙。

## 職業

### 對照方式

- 成長的 `"a,b"` 轉成 `[a, b]`；有前置職業的是 2 轉，`requiredProficiency` 轉成 `proficiencyRequired`；原版沒有能力需求，`statRequirements` 為空。

## 怪物

### 對照方式

- 屬性的地水火木風毒轉成 1～6；子地區名稱轉成該地點的子地區編號 1～4。
- `str`、`smart`、`vit`、`be` 給技能的「能力比對手高」條件比較；`life`、`image`、`npcMessage` 沒有搬：現有戰鬥規則用不到。
- 任務怪（`missionId` 有值）在任務 4.2 與任務一起匯入。

## 技能

### 對照方式

- 原版技能以 `skill-<第 1 級的 id>` 匯入；每級的 `cost` 轉 `money`、`proficiency` 照搬；`description` 留空，`text` 只用來擷取數值。
- 主動技能：說明有涵蓋全部效果的機率就當 `Chance` 條件，否則每級加 `Chance min(100, 30 + 10·lv)`；`sp` 轉成 SP 消耗、`duration` 轉成各效果的 `rounds`。
- 被動技能：說明沒寫條件的是常駐，原版的 `passiveRate`、`sp`、`duration` 不採用；說明有條件的照主動技能的方式轉。
- 寫在「使敵人無法行動」、追加傷害、對手能力降低、封鎖技能上的機率，轉成那個效果自己的 `chance`。
- `need_sid` 轉成 `prerequisite`；魔劍、魔盾的每種屬性只有一列（原版等級 2～6 是同系列的編號），本作各為 1 級。
